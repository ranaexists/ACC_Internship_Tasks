# Analytics Career Connect - Internship Tasks (Phase 2: Day 3)

**Overall Internship Day:** 6
**Focus:** Web Scraping, API Data Extraction, and Startup Operations.

This repository contains the practical implementations and theoretical learnings from Phase 2: Day 3 of the Analytics Career Connect Internship program.

## 🛠️ 9:00 AM to 4:00 PM Slot: Core Skill Development
**Focus:** Data Skills, Web Scraping & Dashboard Building

### 📌 Task 1: Web Scraping & API Learning (Practice Projects Completed)
1. **`01_API_Extraction.ipynb`**: Extracted data from a public API using the Python `requests` library and handled JSON responses.
2. **`02_Static_Scraping.ipynb`**: Used `BeautifulSoup` (`bs4`) to parse HTML and extract specific elements (text and classes) from a static webpage.
3. **`03_Data_to_CSV.ipynb`**: Combined web scraping with `pandas` to structure extracted data into a DataFrame and exported it as a `.csv` file for analysis.
4. **`04_Pagination_Scraping.ipynb`**: Developed a scraper loop to navigate through multiple pages and compile a single consolidated dataset.
5. **`05_NoCode_Scraping.ipynb`**: Explored No-Code scraping via Google Sheets (`IMPORTHTML`, `IMPORTDATA`). Documented technical limitations regarding server-side blocks, validating the necessity of Python-based scrapers.
